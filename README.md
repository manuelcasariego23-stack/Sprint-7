# Sprint-7
Repositorio del proyecto final del sprint 7 de curso para data analyst de triple ten 
Su objetivo es ofrecer una herramienta interactiva para explorar un conjunto de datos de vehículos usados.

Funciones 
Carga y limpieza automática de datos.
- Botón para generar un **histograma del precio**de los vehículos.
- Botón para generar un **gráfico de dispersión** que muestra la relación entre **kilometraje y precio**, diferenciando por tipo de combustible.
- Gráficos interactivos creados con **Plotly Express**.
- Implementación web con **Streamlit**

Recursos utilizados 
- Python 3.10
- pandas
- plotly-express
- streamlit

Ejecucion local 
bash 
git clone [text](https://github.com/manuelcasariego23-stack/Sprint-7)
cd Sprint-7
pip install -r requirements.txt
streamlit run app.py
